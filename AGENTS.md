# SignConnect workspace instructions

Before any UI design, redesign, or frontend styling work, read the root `DESIGN.md` completely and treat it as the visual source of truth.

Reuse tokens, button variants, interaction states, typography, spacing, and accessibility rules from `frontend/styles/system.css` before writing component-specific CSS. If a new reusable pattern is required, update both `DESIGN.md` and `system.css` in the same change.

Preserve product behavior and privacy disclosures. Validate material interface changes in the running desktop app.
